オスカー・ピーターソン Jazz Exercise 1〜3：粒・脱力・タイム感

  1. ♩=60前後で各曲を通す
    • 音量、タイミング、音の長さを揃える
    • 力まず、小さい音でも均一に弾く
    • 止まった箇所に印をつける
  2. 崩れた箇所を2〜3個だけ部分練習
    • 1〜2拍、長くても1小節に切る
    • 移動で崩れる場合は、小節の境目をまたいで練習する
    • 右手5回 → 左手5回 → 両手5回
    • 5回連続で綺麗に弾けたら、前後をつなぐ
    • 難しければ♩=40〜50まで落とす
  3. 速い箇所はリズム変奏
    • 長短、短長で弾く
    • 最後に元の均等なリズムへ戻す
  4. 仕上げにもう一度通す
    • 直した箇所が流れの中でも崩れないか確認する
    • 余裕があれば録音して聴く
